# Treino Diário

App de treino: programas, treinos (catálogo e personalizados), execução com cronômetro/contador, progresso (calorias, peso), nutrição (refeições, macros, água), dados corporais/IMC, conquistas e lembretes.

- frontend/: React + Vite + Tailwind.
- backend/: Express + Prisma (PostgreSQL).
- Login inicial: `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` do `.env` do servidor (a senha nunca vai para o repositório; sem ela o admin inicial não é criado). Outros usuários se cadastram pela tela de login.
